# Receipt Scanner

Photograph a receipt, get structured data — merchant, date, line items, totals, tax. TrOCR + receipt parsing heuristics.

**[Try it](https://freeagentstore.online/a/receipt-scanner/)** | [API Docs](https://freeagentstore.online/agents/receipt-scanner/)
